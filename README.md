# 🎓 SnapClass – AI-Powered Attendance Management System

SnapClass is an AI-powered attendance management application designed
to simplify classroom attendance and subject management.

The application provides separate interfaces for teachers and students,
with features for managing subjects, enrolling students, and recording
attendance using computer vision.

## 🚀 Features

### 👨‍🏫 Teacher Dashboard
- Manage subjects.
- View subject information and student details.
- Access AI-assisted attendance functionality.
- Capture or upload images for attendance processing.
- Manage attendance records.

### 👨‍🎓 Student Dashboard
- View available subjects.
- Enroll in subjects.
- Unenroll from subjects.
- Access subject-related information.

### 🤖 AI Attendance
- Process images for attendance analysis.
- Integrate computer vision into the attendance workflow.
- Support an AI-assisted approach to classroom attendance.

### 🗄️ Database Integration
- Supabase integration for backend data management.
- Store and retrieve application data.
- Support subject, student, and attendance workflows.

## 🛠️ Technologies Used

- Python
- Streamlit
- Computer Vision
- Supabase
- Git and GitHub

## 🏗️ Application Architecture

1. Users access the application through the Streamlit interface.
2. Teachers and students use their respective dashboards.
3. Subject management and enrollment features support classroom
   organization.
4. The AI attendance workflow processes submitted images.
5. Supabase provides database functionality for supported operations.
